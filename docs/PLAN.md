# These Things Matter — phase 2 (front-page fidelity) build plan
Derived from docs/SPEC.md v2.0 (commit 7ea05a1, incl. §6.7) on 2026-09-21. SPEC.md wins over this file.

## Decisions
- Phases → SPEC §8's five phases (0 Harness, 1 Chrome, 2 Lead row, 3 Section rows/Writing/strip, 4 Phone/a11y/close-out), in order, never merged. Each phase ends with a push task that runs `npm run screenshots`, commits the PNGs and logs `Manual check: NOT VERIFIED (human)`.
- Branch → `refine/<date>` from `main` (SPEC §7 `foundry.json`). Commit signing stays on; if a commit fails with a 1Password signing error, run `git config --local commit.gpgsign false` once and continue (owner-authorised). `FOUNDRY_FEEDBACK.md` at the repo root is the owner's log: never stage, move or delete it.
- Rule 34 collection rule (SI: SPEC counts "eleven" unstyled classes; the real count on `main` is 46 — see Spec issues) → a `ttm-*` token counts only when it appears inside a `class="…"`/`class='…'` attribute, a `"className":"…"` block-comment attribute, or as the first argument of `Helpers::wrapper()`; tokens ending in `-`/`_` (body-class prefixes) and `is-*` are ignored; wp-admin-only sources are skipped (`src/Admin/**`, `src/Editor/**`, `src/Cli/**`, `src/Verse/Admin.php`, `src/Taxonomy/SeriesAdmin.php`, `src/Fiction/Books.php`); CSS sources are `assets/css/ttm.css` **and** `style.css`. Allow-list lines are `<pattern> # <reason>` where the pattern may use `*` and `{a,b}` groups; the script fails at ≥ 10 pattern lines, on any uncovered class, and on any dead `ttm-*` selector (the allow-list silences both directions). Later-flight inner-page families are grouped one line per screen so the list stays under 10.
- Colour vs a11y (SI) → any text under 18.66px that §6.2 asserts as `accent` or `neutral-600` is rendered and asserted as `accent-700` / `neutral-700` (rows `mast-current`, `cell-head-link`, `writing-btn`; the byline "by"). Reason: `#ec3013`/`#7d7979` on `#f3f2f2` are 3.77:1/3.85:1, an axe *serious* `color-contrast` violation, which the `a11y` row forbids; 01 §2.1 already says accent text ≤ 17px is accent-700; phase 1 P8-07 set the same precedent. The poster ghost button (bg text on the accent field, 3.77:1) is the one exception 01 §2.1 explicitly permits: axe scans exclude `.ttm-poster .btn-ghost`.
- Layout ownership → every front-page part/pattern group whose layout `ttm.css` defines (masthead rows, title row, lead row, `ttm-lead-row__lead`, rail, cell headings, section rows, series strip, poster, footer and its left column) uses `"layout":{"type":"default"}`; `ttm.css` owns `display`, `gap`, `align-items`. Rule 36 is applied to all 12 `is-style-grid-*` groups in `themes/ttm-theme/**` (inner templates included: it is a shared-chrome fix, not a redesign).
- Current section (R1) → `Nav\CurrentSection::add_class()` adds both `current-section` and core's `current-menu-item`; on `is_front_page()` with `nav.front_current === 'lead'` the link whose path equals the lead post's primary-category archive path is current (`Query\Lead::id()` + `Meta\PrimaryCategory::id()`); `'none'` marks nothing on the front page. The same filter fills a `/category/<slug>/` link's label from the term name when `<slug>` is in `sections.order` (§6.1.8), so `parts/footer.html` stays static HTML (rule 40).
- Masthead meta links → one `core/paragraph.ttm-masthead-front__links` holding three `<a>` (Newsletter · RSS · About), no navigation block; at ≤ 720 only the first link is shown. The date keeps `ttm/today format=masthead` at both widths (markup cannot vary per viewport).
- Journal rail excerpt → the pattern drops `excerptLength` so core's default (55) applies and never re-trims the plugin's sentence-trimmed excerpt; `Text::sentence_excerpt( $text, $words, $max_words )` extends to a sentence end between `$words` and `$max_words`, else hard-cuts at `$max_words` with "…". `journal.excerpt_max_words` = 55 ⚠️ ASSUMPTION (tuned in P2-05; its docblock notes the coupling to core's default).
- `ttm/category-count` → gains `format: 'entries'` ("All {N} entries"; 0 → "All →"); when bound into `core/paragraph` `content` it returns `<a href="{category archive}">…</a>` (HTML-capable like `ttm/meta-line`); everywhere else plain text.
- Lead media → `render.php` drops `style="aspect-ratio:…"`; `imageRatio: '4-3'` becomes class `is-ratio-4-3`; CSS sets 16/9 at desktop, 4/3 at ≤ 720; the grayscale filter sits on the `figure` (01 §6 "applied to the wrapper").
- Technology featured item → `li.wp-block-post:first-child` is the `200px 1fr` grid and spans both columns; its `.ttm-item` group is `display: contents`; the old `.ttm-item-featured` rule is deleted (dead); the pattern's `core/post-featured-image` carries `className: ttm-item-featured__media`. `ttm/meta-line` gains `readingFormat: 'long'|'short'` (`short` → "9 min").
- Series strip (R5) → `ttm/series-list` `layout` enum gains `strip`; `strip` renders `span.ttm-series-mark` + `span.ttm-series-row__title` + `span.ttm-series-row__meta` only; categories are joined with " · " in every layout.
- Newsletter (R3) → new `Newsletter\Form` renders the §6.3 markup for every form provider; `{n}` is a static per-request counter (`Form::reset()` for tests); `Provider\CustomUrl::available()` is true when the endpoint is valid **or** dev-accept applies (`newsletter.endpoint === ''` and `newsletter.dev_accept` and `wp_get_environment_type() !== 'production'`); `Providers::resolve()` = configured-if-available → `custom-url` if dev-accept applies → `mailto` if fallback email → `none`; `?subscribe=success` is treated like `?subscribed=1`; the Seeder no longer installs Jetpack and writes `ttm_settings.newsletter = ['provider' => 'custom-url', 'endpoint' => '']`.
- Jetpack spike → P1-07 is bounded to one task; if Jetpack cannot be installed in wp-env (offline), the spike records that, treats §6.3's field list as the record and hand-authors the fixture from it, marked "unverified".
- §6.7 editor registration → `build/` stays gitignored and is built before use (`npm run env:seed` runs `npm run build` first; CI already builds); `Blocks\Registrar` no longer strips `editorScript`: when `build/blocks/<name>/index.asset.php` is missing it registers a committed, unbuilt fallback script `plugins/ttm-core/assets/editor-fallback.js` (registers every `ttm/*` block with a `ServerSideRender` edit) and shows an admin notice "run npm run build". SPEC's "no-op" script would not remove the message (the JS registry must contain the block), so the fallback registers the blocks.
- Fidelity mechanics → `tests/e2e/fidelity.spec.js` and `tests/e2e/editors.spec.js` run in their own Playwright project `fidelity` (Desktop Chrome; `testMatch`), excluded from the `desktop`/`phone` projects; each test sets its own viewport (1280 / 390 / 1000). Colours come from a helper that resolves `theme.json` preset hex to `rgb()`. Grid assertions read the resolved px tracks (`grid-template-columns`) and compare; "span 2" reads `grid-column-start`; `margin-left: auto` is asserted as the element's bounding-box `x ≥ 1000`; `::before` content via `getComputedStyle(el, '::before').content` with quotes stripped; `rail-count-phone` counts **visible** entries (markup cannot vary per viewport); `verse-nocopy`/`poster-nomailto`/`footer-copy` count DOM nodes.
- Screenshots → `scripts/screenshots.mjs` (Playwright `chromium` from `@playwright/test`), `npm run screenshots`, against `WP_BASE_URL` (default `http://localhost:8888`), does not reseed; zone crops come from bounding boxes (`section-rows` and `poster-footer` are clips spanning two elements).
- Seed → `docs/fixtures/seed/prose.json` is an array of ≥ 40 original paragraphs; a `posts.json` row has `"paragraphs": N` and optionally `"content"` (a verbatim block-markup prefix); the Seeder builds `content = prefix + N paragraphs`, paragraph k = `prose[(rowIndex + k) % count]`. Slugs `technology-post-2` and `journal-post-1` are kept (e2e `urls.mjs`, series part 2). Six series terms replace phase 1's four. The tagline is set by the Seeder (`update_option('blogdescription', …)`, allow-listed in `forbidden-patterns.sh`) and by `.wp-env.json` `afterStart`.
- Verse copyright (R2) → `Bindings\Sources::verse_copyright()` reads `get_option('ttm_verse')['copyright']` directly (no `Verse` import needed); `verse.copyright_placement` default `footer`.
- Footer line → `Values::footer_line( DateTimeImmutable $now, string $site_name )` returns "{site} · © {Y} Eric Mann · Built on WordPress" ("Eric Mann" is a translatable literal: single author, README non-goal); `ttm/today format=footer` passes `get_bloginfo('name')`.
- `cssBudgetBytes` (R6) → 40960 set in P0-03; measured in P3-05 and P4-04; raised at most once more, with the number in the commit body and log.
- Inner-template smoke → `tests/e2e/lib/urls.mjs` `SCREENS` gains `about: '/about/'` (8 screens).
- CI → `.github/workflows/ci.yml` push branches gain `refine/**` in P0-01.
- Quiet Ledger → 12 published chapters (ch. 12 "Reconciliation"), ch. 13 scheduled, `total_parts` stays 31, cadence "monthly".
- Writing cell link text → "All serials & stories →" at both widths (3a's shorter "All serials →" is not reproduced; markup cannot vary).

## Conventions
- Commit message: title `<ID>: <title>`; body `Goal:` / `Tests:` / `Interpretation:` / `Measurement:` (tuning only) / `Manual check:` — the template is in `CLAUDE.md`.
- After every task: `docs/foundry.json` `verify` (composer lint, composer test:unit, npm run lint, npm run test:unit, npm run build, forbidden-patterns) plus `extraVerify` for the touched prefixes. `npm run test:e2e` needs Docker: it starts wp-env and reseeds itself.
- "Un-fixme row X" means: in `tests/e2e/fidelity.spec.js` change `test.fixme(` to `test(` for that row's test and make it pass; never delete a row. Row ids are §6.2's `id` column; where one id has two viewports the phone one is `<id>` as written (`rule-2-phone`, `lead-media-phone`, …).
- Fidelity row overrides (Decisions, colour vs a11y): `mast-current` → `accent-700`; `cell-head-link` → `neutral-700`; `writing-btn` → `background-color: accent-700`. Everything else is §6.2 verbatim.
- Every CSS addition goes under the component's numbered comment header in `ttm.css` (`/* 4.1 masthead front */` …); every component in §6.1 has its own header block. No hex literals in `ttm.css`; presets via `var(--wp--preset--…)`.
- The `## Log` entry for a task lists: rows un-fixme'd, interpretation choices, measurements, `Manual check:` (or `none`).
- Config keys are read as `Config::get( 'key', <default> )` where `<default>` equals `Config::defaults()` (enforced by `tests/unit/ConfigFallbacksTest.php` from P0-02).
- Group blocks: use `"layout":{"type":"default"}` literally where a task says "layout default".
- Row-to-task map (for the reviewer): rule-* P1-01 · mast-meta/title/byline/byline-phone/nav/nav-gap/hub P1-02 · mast-current P1-03 · verse-nocopy P1-04 · footer-* P1-05 · editor-* P1-09 · poster-* P1-10 · lead-* P2-01 · verse-box/kicker/text/ref/attr P2-02 · rail-* P2-04 · row-* and cell-* P3-01 · tech-* P3-02 · writing-* P3-03 · strip-* P3-04 · a11y, network P4-02.

## Spec issues
- Rule 34 says "the eleven unstyled classes"; on `main` the coverage rule finds 46 markup classes without a selector (7 front-page/chrome classes fixed by this flight plus 39 inner-page block hooks: `ttm-series-bar*`, `ttm-series-featured__*`, `ttm-serial-hero__*`, `ttm-series-toc*`, `ttm-archive*`, `ttm-book*`, `ttm-most-read`, `ttm-category-stats`, `ttm-filter-row`, `ttm-hub-head`, `ttm-journal-stream`, `ttm-entry`, `ttm-numbered`, `ttm-syndication__words`, `ttm-series-progress`, `ttm-series-stats`, `ttm-series-single`). A one-class-per-line allow-list cannot be under 10; the plan uses brace-glob lines grouped by later-flight screen (Decisions). Proposed SPEC edit: allow glob patterns and say "fewer than 10 lines".
- §6.2 `mast-current` (accent, 14px), `cell-head-link` (neutral-600, 11px) and `writing-btn` (bg text on accent, 14px) each fail WCAG AA (3.77:1 / 3.85:1) and would be axe *serious* violations, contradicting the `a11y` row; 01 §2.1 itself requires accent-700 for accent text ≤ 17px. Plan asserts accent-700 / neutral-700 (P8-07 precedent). Proposed SPEC edit: change the three expected values.
- §6.2 `poster-btn` (bg text on the accent field at 14px/800) is 3.77:1; 01 §2.1 explicitly permits it. The a11y scans exclude `.ttm-poster .btn-ghost`; SPEC should say so under the `a11y` row.

- §6.2 `mast-hub` "margin-left auto" on `> a`: `getComputedStyle` resolves `auto` to px; the row is asserted as the hub link's bounding box `x ≥ 1000`, with `margin-left: auto` on the `li`.
